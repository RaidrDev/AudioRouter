// FEATURES

Full control, zero friction

Independent volume per app

Every app gets its own slider and its own live level meter — turn up Spotify without touching anything else.

System-wide control

Output, sound effects, and default device, all from the same menu — no need to open System Settings.

Signed and notarized

Apple Developer ID + real notarization. Gatekeeper accepts it without any weird warnings.

Lives in the menu bar

No Dock icon, no extra windows. One click and you're done.

Native macOS audio

Uses Apple's Process Taps API (macOS 14.4+) — no virtual audio drivers, no kernel extensions.

Updates itself

Checks for new versions in the background and lets you know when there's something new to install.
